A program that ships a 1024x1024 newspaper-style front page summing up Monday 23 November 2026 in six stories — the COP31 climate talks collapsing without a deal, Democrats reaching 258 House seats, India six wickets from victory on the final day in Wellington, Modi meeting Nepal's Shah in Delhi, the resumed search at the burnt Banten candy factory, and the drone-hit Russian ship towed out of Finnish waters. The PNG is drawn by render.py during the build and committed as entry.png; `Run it` below only copies that committed PNG to the output directory (main.py; /output by default). If entry.png is missing, main.py fails with a file-not-found error; it creates the output directory if needed and touches nothing else.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
